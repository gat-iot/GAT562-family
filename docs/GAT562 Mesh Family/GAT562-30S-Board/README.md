# GAT562 30S Board

## 产品简介

GAT562 30S Board 是一款基于 **GAT562 30S Mesh Module** 的开发评估板，搭载 30 dBm 高功率 LoRa 模组，适合需要超远距离通信的产品快速验证与评估。

## 硬件特性

| 特性 | 说明 |
|------|------|
| **核心模组** | GAT562 30S Mesh Module（30 dBm 高功率） |
| **供电** | USB Type-C / DC Jack / 电池接口（≥5V/1A） |
| **天线接口** | IPEX / SMA 可选 |
| **显示接口** | 预留 1.3" TFT 屏幕接口 |
| **调试接口** | USB 烧录 / SWD |
| **尺寸** | 约 85 × 60 mm |

> ⚠️ **供电注意**：30S Board 在高功率发射时峰值电流 ~900 mA，必须使用 5V/1A 以上电源。
