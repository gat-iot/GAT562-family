# GAT562 30S Mesh Kit

## 产品简介

GAT562 30S Mesh Kit 是 GAT562 家族的旗舰手持终端套装，基于 GAT562 30S Mesh Module，配备 **30 dBm（1 W）高功率 LoRa**，是户外贴身使用的最强信号选择，适合野外探险、搜救、海上通信等需要超远距离离网通信的场景。

## 核心配置

| 组件 | 型号/规格 |
|------|----------|
| **LoRa 模组** | GAT562 30S Mesh Module（**30 dBm 高功率**） |
| **主芯片** | nRF52840 + SX1262 + TCXO |
| **显示屏** | 1.3" TFT |
| **定位** | GPS 模块（内置/外接） |
| **输入** | 按键 + 摇杆 |
| **指示** | LED + 蜂鸣器 |
| **供电** | 内置锂电池（≥ 1000 mAh 推荐） |
| **发射功率** | **30 dBm（1 W）** |
| **通信距离** | 15 km+（开阔地，视天线而定） |

## 与 GAT562 Mesh Tracker Pro 的区别

| 对比项 | GAT562 30S Mesh Kit | GAT562 Mesh Tracker Pro |
|--------|---------------------|----------------------|
| 发射功率 | **30 dBm (1 W)** | 22 dBm (158 mW) |
| 通信距离 | **15 km+** | 8-15 km |
| 适用场景 | 超远距离/野外 | 中远距离/城郊 |
| 供电要求 | 高（峰值 900 mA） | 中（峰值 200 mA） |
