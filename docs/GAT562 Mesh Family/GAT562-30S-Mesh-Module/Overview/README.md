# GAT562 30S Mesh Module 概述

## 产品简介

GAT562 30S Mesh Module 是 GAT562 家族中的**高性能增强版本**，相较于标准 GAT562 Mesh Module，其核心升级在于内置外置功率放大器（PA），LoRa 发射功率从标准版的 22 dBm 提升至 **30 dBm（1 W）**，大幅扩展通信覆盖范围，尤其适合山区、海上、荒野等超远距离通信场景。

其他核心配置与 GAT562 Mesh Module 保持一致，同样基于 nRF52840 + SX1262 + TCXO，**与 RAK4631 模组 IO 完全兼容，可直接烧录 RAK4631 全系列固件**。

## 核心特性

| 特性 | GAT562 30S | GAT562 标准版 | 说明 |
|------|-----------|-------------|------|
| **LoRa 发射功率** | **30 dBm (1 W)** | 22 dBm (158 mW) | 外置 PA，显著提升通信距离 |
| **主芯片** | nRF52840 | nRF52840 | ARM Cortex-M4, 64MHz |
| **射频芯片** | SX1262 + TCXO | SX1262 + TCXO | 性能一致 |
| **BLE 发射功率** | +4 dBm | +4 dBm | — |
| **通信距离** | 15 km+（开阔地） | 8-15 km（开阔地） | 视天线和环境而定 |
| **睡眠功耗** | ~2 µA | ~2 µA | 仅 MCU 休眠 |
| **供电电压** | 3.3 ~ 5 V（增强PA供电） | 2.0 ~ 3.6 V | 30S 需更高供电电流 |
| **RAK4631 兼容** | ✅ 完全兼容 | ✅ 完全兼容 | 固件可直接互换 |

## 典型功耗对比

| 模式 | GAT562 30S | GAT562 标准版 |
|------|-----------|-------------|
| 深度睡眠 | ~2 µA | ~2 µA |
| 接收 (LoRa) | ~18 mA | ~17 mA |
| 发射 @17 dBm | ~180 mA | ~92 mA |
| **发射 @30 dBm** | **~900 mA** | N/A |
| **发射 @22 dBm** | **~200 mA** | ~125 mA |

> ⚠️ **注意**：30 dBm 高功率发射时峰值电流可达 ~900 mA，请确保供电能力充足（推荐 5V/1A 以上），并注意散热。

## 适用场景

| 场景 | 推荐版本 | 说明 |
|------|----------|------|
| 城市近距离 Mesh | GAT562 标准版 | 低功耗够用 |
| 郊区 / 城郊通信 | 两者皆可 | 标准版 22 dBm 可覆盖 |
| **山区 / 海上通信** | **GAT562 30S** | 30 dBm 穿透力强 |
| **野外探险 / 搜救** | **GAT562 30S** | 超远距离通信 |
| 太阳能中继站 | GAT562 30S | 高功率中继首选 |
| 低功耗传感节点 | GAT562 标准版 | 电池供电友好 |
