# GAT562 30S Mesh Solar rakay Pro

## 产品简介

GAT562 30S Mesh Solar rakay Pro 是 GAT562 家族的**旗舰级太阳能中继方案**，搭载 **30 dBm（1 W）高功率模组** + 大容量太阳能供电系统，专为超远距离 Mesh 网络中继设计，是楼顶固定中继站的终极选择。

## 核心配置

| 组件 | 规格 |
|------|------|
| **LoRa 模组** | GAT562 30S Mesh Module（**30 dBm 高功率**）|
| **中继类型** | 高功率 |
| **发射功率** | 30 dBm（1 W）|
| **通信距离** | 15 km+（开阔地）|
| **太阳能板** | 大面积（≥ 10W 推荐）|
| **锂电池** | 大容量（≥ 10000 mAh 应对阴天）|
| **天线** | 高增益全向/定向天线（≥ 5dBi）|
| **安装高度** | 越高越好（最佳位置：楼顶中央）|

## 为什么选择 30S 高功率中继？

| 对比项 | 22 dBm 中继 | **30 dBm 中继** |
|--------|------------|---------------|
| 覆盖半径 | 8-15 km | **15-30+ km** |
| 穿透力 | 一般 | **强（适合山区）** |
| 中继跳数 | 3-5 跳 | **8-10+ 跳** |
| 适用地形 | 平原/郊区 | **山区/海上/开阔地** |
| 功耗 | 较低 | 较高（但太阳能可弥补）|

## 部署建议

> ⚠️ **法规注意**：30 dBm 在部分地区使用时需遵守当地无线电法规（占空比限制、天线增益限制等）。

**最佳部署实践：**
1. **选址**：楼顶中央制高点，天线高于周边障碍物
2. **天线**：使用 ≥ 5dBi 全向天线，或定向天线（点对点场景）
3. **供电**：太阳能板朝南（北半球），倾角与当地纬度相同
4. **防护**：使用防水外壳（IP67），避免雨水进入
5. **配置**：Meshtastic 中继模式，设置合适的跳频参数
