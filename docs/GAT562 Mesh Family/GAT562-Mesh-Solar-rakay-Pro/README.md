# GAT562 Mesh Solar rakay Pro（高性能太阳能中继）

## 产品简介

GAT562 Mesh Solar rakay Pro 是 GAT562 家族的高性能太阳能中继方案，相比低成本版 Solar Relay，搭载 **22 dBm 高性能模组 + 更大容量的太阳能系统**，适合需要更稳定、更强信号覆盖的长期部署场景。

## 核心配置

| 组件 | 规格 |
|------|------|
| **LoRa 模组** | GAT562 Mesh Module（22 dBm）|
| **中继类型** | 高性能 |
| **太阳能板** | 更大面积（视部署环境）|
| **锂电池** | 更大容量 |
| **天线** | 高增益外置天线 |
| **防护等级** | IP65+ 户外防护外壳（推荐）|

## 与 Solar Relay（低成本版）的区别

| 对比项 | Solar Relay（低成本） | Solar rakay Pro（高性能）|
|--------|---------------------|----------------------|
| 太阳能板 | 标准尺寸 | 更大面积 |
| 锂电池 | 基础容量 | 大容量（更长续航）|
| 目标场景 | 短期/临时部署 | 长期稳定运营 |
| 覆盖能力 | 中等 | 强 |
