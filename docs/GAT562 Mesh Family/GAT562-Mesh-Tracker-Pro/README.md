# GAT562 Mesh Tracker Pro

## 产品简介

GAT562 Mesh Tracker Pro 是一款基于 GAT562 Mesh Module 的手持 Meshtastic 终端设备，预装 Meshtastic 开源固件，开箱即用，适合随身携带进行 Mesh 网络通信。

## 核心配置

| 组件 | 型号/规格 |
|------|----------|
| **LoRa 模组** | GAT562 Mesh Module（22 dBm） |
| **主芯片** | nRF52840 + SX1262 + TCXO |
| **显示屏** | 1.3" TFT（可选配） |
| **定位** | GPS 模块接口（UART） |
| **输入** | 按键 / 摇杆 |
| **指示** | LED / 蜂鸣器 |
| **供电** | 内置锂电池 |
| **通信** | LoRa Mesh + BLE 5.0 |

## 典型应用

- 📍 **位置共享**：实时将自己的 GPS 位置广播到 Mesh 网络
- 💬 **文字消息**：无网络环境下与队友互发文字消息
- 🚶 **组队出行**：野外徒步、骑行、登山团队的离网通信
- 🏕️ **户外探险**：没有手机信号的偏远地区通信保障
- 🚨 **应急通信**：灾害现场的临时通信保障

## 功能特点

- ✅ **去中心化 Mesh**：无需基站，每个设备都是中继节点
- ✅ **位置追踪**：GPS 实时定位，支持地图显示
- ✅ **消息加密**：AES256 端到端加密
- ✅ **低功耗设计**：nRF52 架构，持久续航
- ✅ **中文界面**：Meshtastic App 支持中文
