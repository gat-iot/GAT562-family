# GAT562 30S Mesh Module 快速入门

## 与 GAT562 标准版的差异

GAT562 30S 的快速入门流程与 GAT562 标准版基本一致，主要差异在于：

| 差异项 | 说明 |
|--------|------|
| **供电要求更高** | 30 dBm 发射时峰值电流 ~900 mA，必须使用 ≥5V/1A 电源 |
| **天线接口** | 30S 采用 IPEX/u.FL 射频座（非邮票孔），需使用 IPEX 天线线或转接线 |
| **发热注意** | 长时间 30 dBm 发射时模组会发热，建议加强散热 |

## 供电注意事项

> ⚠️ **关键警告**：GAT562 30S 在 30 dBm 发射时峰值电流约 **900 mA**。如果使用 USB 供电，请确保使用 **USB 3.0 端口**或 **5V/1A 以上**的电源适配器。如果使用锂电池供电，请使用 **3.7V 锂聚合物电池（容量 ≥ 1000 mAh）**。

**推荐供电方案：**
```
✅ 推荐：
  - USB 5V/1A 以上电源适配器 + USB-C 数据线
  - 3.7V LiPo 电池（≥1000mAh）+ USB 充电管理模块
  - 太阳能电池板 + LiPo 电池（太阳能中继场景）

❌ 不推荐：
  - USB 2.0 电脑端口（仅提供 500mA）
  - 直接使用 3.3V/500mA 电源（供电不足，发射会断电重启）
```

## 天线选择

| 天线类型 | 适用场景 | 建议 |
|----------|----------|------|
| IPEX 1/4 波段天线 | 便携设备 | 小型化，轻便 |
| SMA 直立天线（3dBi） | 固定中继 | 增益更高 |
| SMA 胶棒天线（5dBi） | 远距离固定点 | 高增益首选 |
| 外置高增益天线 | 楼顶中继站 | 10dBi+ 全向/定向天线 |

> **天线匹配**：确保天线阻抗为 **50 Ω**，并使用阻抗匹配的射频线缆（如同轴线）。

## Meshtastic 固件烧录

### 方法一：Web Flasher（推荐）

1. 访问 [meshtastic.org/flasher](https://meshtastic.org/flasher)
2. 选择目标设备：`RAK4631`（GAT562 30S IO 兼容）
3. 选择版本和频段（与您的 30S 模组匹配）
4. 用 USB 连接设备
5. 点击 **Flash**

### 方法二：蓝牙 OTA

1. 开机后，打开 Meshtastic App
2. 连接设备（BLE）
3. 设置 → 检查固件更新 → 安装

## LoRa 参数配置建议（30S 专用）

由于 30 dBm 高功率特性，建议以下配置：

| 场景 | 发射功率 | 扩频因子 | 带宽 | 说明 |
|------|----------|----------|------|------|
| 超远距离固定中继 | 30 dBm | SF10 | 125 kHz | 最大覆盖 |
| 户外探险（平衡模式） | 22 dBm | SF9 | 250 kHz | 距离与功耗平衡 |
| 低功耗传感器节点 | 10 dBm | SF7 | 500 kHz | 省电优先 |
