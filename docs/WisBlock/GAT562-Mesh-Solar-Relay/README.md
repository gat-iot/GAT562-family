# GAT562 Mesh Solar Relay（低成本太阳能中继）

## 产品简介

GAT562 Mesh Solar Relay 是一款基于 GAT562 Mesh Module 的低成本楼顶/户外固定中继设备，预装 Meshtastic 固件，搭配太阳能电池板和锂电池，形成完全自主供电的 Mesh 网络节点，显著延伸 Mesh 通信覆盖范围。

## 核心配置

| 组件 | 规格 |
|------|------|
| **LoRa 模组** | GAT562 Mesh Module（22 dBm） |
| **发射功率** | 22 dBm |
| **中继类型** | 低成本 |
| **供电方案** | 太阳能 + 锂电池 |
| **天线** | 外置高增益天线（推荐 5dBi+） |
| **安装方式** | 壁挂 / 抱杆 |

## 典型部署

```

   └─────────┘
```

## 配置建议

| 参数 | 推荐值 |
|------|--------|
| LoRa 发射功率 | 20~22 dBm（白天）|
| 睡眠间隔 | 按需设置（Mesh 路由自动唤醒）|
| 天线类型 | 全向 5dBi（覆盖均匀）或定向（点对点）|
| 天线安装高度 | 越高越好（视距传播）|
| 锂电池容量 | ≥ 5000 mAh（应对连续阴天）|

## 优势

- ✅ **低成本**：适合大面积铺设
- ✅ **自供电**：太阳能 + 锂电池，零电费
- ✅ **免维护**：Mesh 自组网，自动路由
- ✅ **延伸距离**：显著扩大 Mesh 网络覆盖半径
