# GAT562 Mesh Watch

## 产品简介

GAT562 Mesh Watch 是一款可穿戴形态的 Meshtastic Mesh 通信终端，将 GAT562 Mesh Module 集成于手表形态的机身中，专为需要随身通信又不希望携带独立设备的用户设计，适合户外运动、可穿戴追踪等场景。

## 核心配置

| 组件 | 型号/规格 |
|------|----------|
| **LoRa 模组** | GAT562 Mesh Module（22 dBm） |
| **主芯片** | nRF52840 + SX1262 + TCXO |
| **显示屏** | 手表屏幕（1.x" TFT） |
| **定位** | GPS 模块（可选） |
| **传感器** | 加速度计等运动传感器（依批次） |
| **供电** | 内置锂电池 |
| **通信** | LoRa Mesh + BLE 5.0 |

## 典型应用

- 🏃 **运动追踪**：跑步、骑行时的位置共享与通信
- ⛰️ **户外运动**：轻量级离网通信
- 👥 **团队联络**：无需掏出手机，快速收发消息
- 📍 **位置监控**：家人/队友之间实时位置共享
